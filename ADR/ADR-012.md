# ADR-012: Reproducible Evaluation of Retrieval and the Gate

**Date:** 2026-10-10
**Status:** Accepted

## Context

The retrieval numbers in ADR-007 (recall@3 = 12/12 for both the linear blend and RRF) came from `scripts/eval_retrival.py`. That script fed each query the `causal_chain` and `affected_components` of its own label, so the structural signals were 1.0 by construction (leakage). The gate decisions, the topology fix (DID-22) and the cosine fix had no measurements at all.

## Decision

A single command, `python -m experiments.run_all`, regenerates every table under `experiments/results/` (`retrieval`, `gate`, `ops`, `summary`, as `.json` and `.md`). It needs no API key. `scripts/eval_retrival.py` is removed.

- **Production code only.**
  - Retrieval goes through `HybridRetriever.retrieve_scored`; the per-signal ablation reads its breakdown, so the fusion is never re-implemented.
  - The gate replays events through HTTP adapter → correlator → the CRITICAL trigger → `LiveInvestigation`. The agent is a stub that cites the best candidate, because here the gate is under test, not the model.
- **No leakage.** The retrieval dataset (`experiments/datasets/retrieval_queries.json`) is text only:
  - 12 original queries from `test_queries.json`, with their structural labels dropped;
  - 12 paraphrases and 4 hard negatives, written by us;
  - 3 queries with no correct runbook.

  Structure only comes from live events. The old label-fed setup is still reported, as an upper bound.
- **Before/after measurements:**
  - *Topology fix*: the same events replayed with a topology where every component calls every other, which is what the rules did before DID-22.
  - *Cosine fix*: the old semantic score `max(0, 2·cos − 1)` (squared L2 on unit vectors read as a cosine distance), re-blended with the other signals.
- **LLM out of scope here.** Citations, scope refusal, injection, latency and cost per model are measured by `experiments.model_selection` (ADR-011). `run_all` copies that study's figures into `ops` when its results are present.

## Results (2026-10-10)

| | Recall@1 | Recall@3 | MRR |
|---|---:|---:|---:|
| Hybrid, text only, 28 queries | 0.82 | 0.96 | 0.90 |
| — original 12 / paraphrases 12 / hard negatives 4 | 1.00 / 0.67 / 0.75 | 1.00 / 0.92 / 1.00 | |
| Semantic signal alone, 28 queries | 0.93 | 1.00 | 0.96 |
| BM25 alone, 28 queries | 0.61 | 0.71 | 0.70 |
| Old setup, labels as structure (12 originals) | 1.00 | 1.00 | 1.00 |

Random recall@3 = 0.30. All 3 no-match queries stay below the 0.5 threshold (best 0.24–0.28).

**Gate:** 6/6 decisions correct at 0.5:
- 3 known incidents → FULL, with the right runbook ranked first;
- the novel incident → CHAIN_ONLY;
- the degrading scenario and the false-causality case → no investigation.

Every threshold from 0.35 to 0.65 gives the same 6/6, so 0.5 sits in the middle of the safe band. At 0.30 the novel incident (best 0.34) would reach the LLM; at 0.70 two of the three known incidents would not.

**Topology fix:** without the topology, the synthetic case (auth memory → payment timeout → checkout health check; payment does not call auth) becomes a CRITICAL chain and a FULL investigation, so the LLM is called on a false cause. With the topology, it stays a 1-hop incident.

**Cosine fix:** on these scenarios the old score lowers the best match from 0.67–0.74 to 0.60–0.63, but no gate decision changes: the fix bought margin, not decisions.

## Consequences

- **The 12/12 of ADR-007 was not inflated by leakage on the original queries**: text-only also gets 12/12 on them. The hard cases are the paraphrases.
- **Linear blend vs semantic alone:** on text-only queries the blend is *worse* than semantic alone at rank 1 (0.82 vs 0.93), because BM25 latches onto surface words ("cache", "pods", "restarts") and hurts 4 of the 12 paraphrases. The hybrid earns its keep through the structural signals, which only exist when there are live events.
- **ADR-007's claim that a component weight above 0.25 degrades hard-negative separation is not backed by this suite.** Text-only queries have no component signal, and five live scenarios are too few to sweep weights. It remains a design assumption.
- **Limits:**
  - Small hand-made dataset; paraphrases and hard negatives were written by the authors.
  - 6 scenarios, which cover every gate outcome but no noise.
  - The crash trigger (DID-43) is not in this replay yet.
  - Latencies come from one machine.
